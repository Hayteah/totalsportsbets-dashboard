## 2026-07-19 - Semantic Toggle Controls in Inline-Styled Layouts
**Learning:** In dashboards utilizing pure inline styling without global stylesheet overrides, custom interactive components like toggle switches are frequently coded as simple `div` containers with click handlers. This breaks keyboard focus, tab ordering, and screen reader identification. Simply adding semantic roles like `role="switch"` or ARIA attributes to `div` elements is insufficient because they still cannot be focused by keyboard users unless a `tabIndex` is added and keydown handlers are manually bound.
**Action:** Refactor custom `div` wrappers to semantic `<button type="button">` wrappers, explicit `padding: 0`, and `outline: 'none'`, while managing active focus styling via React state (`onFocus`/`onBlur`) to preserve pixel-perfect visual design layout while achieving full accessibility.
