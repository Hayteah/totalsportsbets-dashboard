# Palette's Journal - Totalsportbet Dashboard

## 2025-05-14 - Accessible Toggle Component
**Learning:** In this project, custom focus/hover effects for icon buttons should be implemented using state-driven inline styles rather than direct DOM manipulation, as the project uses a custom-styled dark theme without global focus resets.
**Action:** Use `useState` to manage `isFocused` state and apply inline `outline` styles to ensure focus visibility in dark-themed dashboards.
