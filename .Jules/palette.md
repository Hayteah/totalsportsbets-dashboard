## 2025-05-14 - Branding Integration and Verification

**Learning:** Integrating SVG assets directly into a Next.js dashboard requires careful container styling (object-fit, overflow) to prevent layout shifts. Using Playwright for visual verification with video recording is essential for confirming branding consistency across different tabs.

**Action:** Always verify branding assets in their final UI context using automated screenshots and videos to ensure color accuracy and proper scaling.
