## 2025-02-15 - Accessible Toggle Components with Custom Inline Styles
**Learning:** In a pure React application where layout and styling are handled through inline styles, custom interactive elements (like custom Switch/Toggle elements) often default to simple `div` containers with `onClick` handlers. This creates massive accessibility gaps because screen readers cannot interpret them, and keyboard-only users cannot focus or operate them. Implementing them with a `<button type="button">` using `role="switch"` and `aria-checked` provides instant native keyboard and screen-reader support. To preserve design alignment without introducing default browser button outlines, managing focus state via React's `useState` (`isFocused`) and conditionally applying `boxShadow` provides a clean, custom visual outline.
**Action:** Always replace pure `div` click containers with semantic HTML elements (like `button`) or specify proper interactive ARIA roles, states, and focus event handlers. Use inline focus state hooks to render accessible outlines when default browser outline style is reset.
