# Palette's Journal

## 2025-04-26 - Branding Identity and SVG Assets

### Visual Identity
- **Primary Background**: `#08080d`
- **Card Background**: `#0f0f18`
- **Accent Green**: `#00FF88` (Neon Green)
- **Accent Blue**: `#00AAFF` (Neon Blue)
- **Gradient**: 135-degree linear flow from Neon Green to Neon Blue.

### Branding Assets
The following assets were generated and stored in `public/branding/`:
- `instagram-pfp.svg`: Profile picture for Instagram (Primary background).
- `facebook-pfp.svg`: Profile picture for Facebook (Primary background).
- `twitter-pfp.svg`: Profile picture for Twitter (Primary background).
- `youtube-pfp.svg`: Profile picture for YouTube (Circular safe-area design with modified logo path).
- `homepage-icon.svg`: Branding icon with transparent background.
- `template-icon.svg`: Branding icon with card background.

### Design Notes
- The lightning bolt logo uses path `M 550 150 L 250 550 L 450 550 L 350 850 L 750 450 L 550 450 L 750 150 Z` for standard assets.
- For `youtube-pfp.svg`, the path was modified to `M 550 250 L 350 500 L 480 500 L 420 750 L 650 450 L 520 450 L 650 250 Z` to ensure it fits within the circular safe-area.
- All SVG assets are 1000x1000 and use a 1000x1000 viewBox.
