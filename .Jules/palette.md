## 2026-05-31 - Themed Branding Assets Generation and Integration

**Learning:** Generating themed branding assets as SVGs allows for high-quality, scalable icons that maintain visual consistency across different platforms and UI components. Using specific paths for safe-areas ensures that critical elements like logos are not cut off when used as circular profile pictures.

**Action:** Always use SVG for branding assets to ensure scalability and visual consistency, and provide safe-area variants for platform-specific requirements like circular profile pictures.
