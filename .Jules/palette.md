## 2025-05-23 - [Branding Integration]
**Learning:** When integrating SVG assets with gradients into a dashboard, using `<img>` tags is safer than inlining SVG to avoid ID collisions and ensures easier management. PFP-specific SVGs need internal padding (safe-area) to avoid being cut off by circular masks on social platforms.
**Action:** Always provide PFP-optimized versions of logos and use a robust rendering pattern that handles both local assets and fallback emojis.
