## 2026-06-07 - [Accessible Micro-Interactions]
**Learning:** Custom interactive elements like toggles and icon-only buttons need semantic HTML (e.g., <button>) and ARIA attributes (role='switch', aria-label) to be usable by screen readers and keyboard users.
**Action:** Always prefer <button> over <div> for clickable elements and ensure every icon-only action has a descriptive aria-label.
