## 2025-05-14 - [Accessibility Improvements for Dashboard Toggles and Actions]
**Learning:** Refactoring non-semantic `div` elements into proper `button` elements with `role="switch"` significantly improves accessibility for screen readers. Adding `aria-label` to icon-only buttons is essential.
**Action:** Always use semantic HTML elements for interactive components and ensure descriptive ARIA labels are present for all icon-only actions.
