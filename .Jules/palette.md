## 2026-06-20 - [A11y Refactoring: Toggles & Status Indicators]
**Learning:** Generic 'div' based interactive elements and status indicators lack semantic meaning for assistive technologies. Refactoring them into standard HTML elements with appropriate ARIA roles significantly improves accessibility without impacting visual design.
**Action:** Always prefer semantic buttons for toggles and ensure all status-only icons have descriptive aria-labels.
