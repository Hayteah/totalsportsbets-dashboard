## 2026-05-26 - [Accessibility & Micro-UX Enhancements]
**Learning:** Converting non-semantic interactive elements (like `div` toggles) to proper `button` elements with `role="switch"` significantly improves keyboard navigability and screen reader support. Explicit `aria-label` attributes for icon-only buttons are essential for clarity.
**Action:** Always use semantic HTML elements for interactive components and ensure focus states are visually distinct using `outline` or similar techniques.
